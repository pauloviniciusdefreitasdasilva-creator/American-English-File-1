# Original full course parts

The original four gzip files are split into ten binary chunks so every upload is below GitHub's 25 MB browser limit. Extract the provided chunks ZIP and upload all ten .part files into this folder, preserving their exact names:

- course-01.html.gz.part01 and course-01.html.gz.part02
- course-02.html.gz.part01 and course-02.html.gz.part02
- course-03.html.gz.part01, course-03.html.gz.part02, and course-03.html.gz.part03
- course-04.html.gz.part01, course-04.html.gz.part02, and course-04.html.gz.part03

Do not upload the old unsplit .html.gz files. The full-course.html loader automatically joins each group in order, decompresses it, and opens the original interactive course with its embedded media. Keep the root index.html unchanged.
